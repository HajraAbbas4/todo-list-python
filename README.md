# To-Do List Application

This project is a simple desktop-based To-Do List application developed using Python and the Tkinter GUI library. The application helps users manage daily tasks by allowing them to add and delete tasks through a graphical user interface.

The project demonstrates the basic concepts of GUI application development, event handling, list management, and user interaction in Python. It provides an easy and user-friendly interface for organizing tasks efficiently.

## Features
- Add new tasks to the list
- Delete selected tasks
- User-friendly graphical interface
- Warning messages for empty inputs and invalid selections
- Simple task management system

## Technologies Used
- Python
- Tkinter GUI Library

## Working Principle
1. The user enters a task in the input field.
2. Clicking the "Add Task" button stores the task in the list.
3. Tasks are displayed in the list box.
4. The user can select and remove tasks using the "Delete Task" button.
5. Warning messages are displayed for invalid actions.
